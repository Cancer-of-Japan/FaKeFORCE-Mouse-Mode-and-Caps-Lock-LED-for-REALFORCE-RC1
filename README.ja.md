# フェイクフォース：リアルフォース RC1のためのマウスモード、Caps Lock　LED　表示

Topre REALFORCE RC1 にCaps　Lock　LED　表示、キーボードのAPC機能を使ってマウスを操作する Windows アプリです。キーの押し込み深さを読み取り、ポインター移動、クリック、スクロールに変換します。

> **Windows 専用:** このバージョンの動作には Windows と .NET 8 SDK が必要です。アプリの実行中は REALFORCE キーボードを接続したままにしてください。アプリを終了するかキーボードを取り外すと、マウス操作と LED エフェクトは停止します。（私は Linux/Mac ユーザーで、Microsoft 製品ははっきり言って嫌いですが、世は民主主義なのでどうしようもない。将来的には Mac と Linux にも対応する予定です。）

> **プロジェクトに関する注意:** このプロジェクトはバイブコーディングで作成しました。REA を使って元のソフトウェアとファームウェアをリバースエンジニアリングし、その動作を理解しています。機能、性能、UI は十分に検証されておらず、実験的なソフトウェアです。不完全または不安定な可能性があるため、重要な用途には使用しないでください。

## 制作した理由

Topre は素晴らしいキーボードを作っています。私が初めて Topre のスイッチを体験したのは、日本のセブン-イレブンにある ATM のテンキーでした。どうやら REALFORCE と同じスイッチが使われているようです。その体験がきっかけで REALFORCE RC1 を購入し、すっかり気に入りました。このキーボードで文章を書くと、日常の作業まで芝居がかったものに感じます。AI に「JSONってだれ？」と尋ねると、ソクラテスがプラトンに思想を問いただすような気分になり、取引先へのメールを書くとキケロが元老院に手紙を書いているようで、Teams で締切について PM に苦情を言うと三島由紀夫になった気分です。私にとって、このキーボードはダ・ヴィンチとミケランジェロの合作のような存在です。

ただ、RC1 には残念な点があります。Topre の設定ソフトは R4 や GX1 など一部のモデルではマウスモードや Caps Lock LED 表示に対応していますが、RC1 にはその機能がありません。私のリバースエンジニアリングでは、RC1 はステータス LED のエフェクトを動かせるように見えますが、公式ソフトからは利用できません。Godfatherでマイケルを裏切ったフレドのように、私は少し裏切られた気分でした。

「意志あるところに道は開ける」という気持ちと GPT-5.6 Luna の助けを借り、REA で元のソフトウェアとファームウェアの LED 制御経路を調べました。その成果が FaKeFORCE です。RC1 にマウスモードと Caps Lock LED エフェクトを追加する、実験的なコンパニオンアプリです。

## 機能

- W/A/S/D: アナログキーの押し込み深さに応じてポインターを移動します。
- Q/E: 左クリック／右クリック。
- J/K: 下／上にスクロール。
- Fn + Right-Shift: マウスモードのオン／オフ。
- マウスモード中はステータス LED が RGB で変化します。Caps Lock が優先され、LED が赤く点滅します。エフェクトは一時的なもので、キーボードのファームウェアや保存済みのライティング設定は変更しません。
- Caps Lock のエフェクトはキーを押した瞬間だけではなく、Windows の Caps Lock が有効な間ずっと動作します。有効中はマウスモードの LED エフェクトに代わり、設定した色とタイミングで点滅します。色と点滅間隔は **LED Effects** で変更できます。LED エフェクトを無効にすると、両方のエフェクトが停止します。この機能の使用中はアプリを起動し、キーボードを接続しておく必要があります。
- 設定画面では、速度、デッドゾーン、Power または S 字カーブ、キー割り当て、起動ショートカット、LED エフェクトを変更できます。

## インストールと起動

1. Microsoft から **[Windows 用 .NET 8 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)** をインストールします。インストール後、新しい PowerShell ウィンドウを開いてください。
2. REALFORCE RC1 キーボードを接続します。
3. リポジトリのフォルダーで PowerShell を開き、次を実行します。

   ```powershell
   cd .\src
   dotnet run
   ```

初回起動時にアプリがビルドされ、バックグラウンドで起動し、Windows へのサインイン時に自動起動するよう登録されます。時計の近くの通知領域にアイコンが表示されます。コマンドが終了したら PowerShell を閉じてもアプリは動作し続けます。

Fn + Right-Shift を押すとマウスモードがオンになります。もう一度押すとオフになります。マウスモード中は、割り当てられた移動、クリック、スクロール用キーは他のアプリへの通常の入力として使えません。

## 設定を開く

トレイアプリの実行中に、リポジトリ内の `src` フォルダーで PowerShell を開いて次を実行します。

```powershell
dotnet run --no-build
```

実行中のアプリに設定画面を表示するよう通知します。マウスコントローラーが二重に起動することはありません。トレイアイコンを右クリックして **Mouse sensitivity...** を選んでも開けます。

- **Mouse Mode:** 起動ショートカットの概要。
- **Sensitivity:** 移動速度、デッドゾーン、カーブ形状、カーブの強さ。Power は遅い動きから速い動きへ変化し、S 字カーブは始めと終わりをなめらかにし、中間で強く反応します。
- **Key Assignment:** 移動、クリック、スクロール、起動に使うアナログスロットとキーボードキー。
- **LED Effects:** LED エフェクトの有効／無効、色とタイミング、プレビュー。

変更は実行中のアプリに反映されます。今後の起動にも適用するには **Save** を押してください。設定は `%APPDATA%\RealforceApcMouse\settings.json` に保存されます。

## 終了と自動起動の無効化

トレイアイコンを右クリックして **Quit** を選ぶとアプリが終了します。Windows サインイン時の自動起動設定は削除されません。

自動起動を無効にするには、アプリの実行中に `src` フォルダーで PowerShell を開き、次を実行します。

```powershell
dotnet run --no-build -- uninstall
```

このコマンドだけではアプリは終了しません。停止するにはトレイメニューから **Quit** を選んでください。再度 `dotnet run` を実行するとアプリが起動し、自動起動も再登録されます。

## ビルドとトラブルシューティング

アプリを起動せずにビルドするには、次を実行します。

```powershell
cd .\src
dotnet build
```

`realforce-apc-mouse.exe` がロックされているというエラーが出た場合、バックグラウンドアプリがまだ実行中です。トレイメニューから **Quit** を選び、その後 `dotnet run` を実行してください。Windows の自動起動はこのフォルダー内の実行ファイルを参照するため、初回起動後にリポジトリを別の場所へ移動しないでください。

キーボードが見つからない場合は、接続を確認し、`src` から `dotnet run -- list` を実行してください。`dotnet run -- scan` はアナログスロット番号の確認に使えます。`dotnet run -- status 17 --watch` は指定スロットを監視します（`17` は調べたいスロット番号に置き換えてください）。診断コマンドは Ctrl+C で終了できます。

`dotnet run -- led-test` は任意のハードウェア診断です。確認後、LED 設定ブロックに一時的な値を書き込み、元に戻します。キーボードの保存済みライティング設定をテストしたくない場合は実行しないでください。
